# Trammel

A "safe" mirror of Felucca, created after the Time of Legends storyline —
same geography, same city names at the same X/Y coordinates, but
non-consensual PvP is off outside of special event areas, and death does not
drop your entire pack. This is the default facet for most new characters and
the safer choice for an agent that wants to explore without risking full-loot
death. It is still a *different map* than Felucca: you cannot `goto` from one
to the other, only travel via `moongates.md` or a recall/gate spell.

See `overview.md` for the coordinate system and general travel method, and
`moongates.md` for the fixed public-gate network (Moonglow, Britain, Jhelom,
Yew, Minoc, Trinsic, Skara Brae, Magincia, New Haven on this facet).

All coordinates below are sourced verbatim from this server's
`Data/Locations/trammel.json`. Dungeons, shrines, and most towns are
identical in coordinates to `felucca.md`; this file calls out only what's
different (Heartwood, Haven/New Haven replace Felucca's Ocllo) and repeats
the rest for convenience so this file is self-contained.
